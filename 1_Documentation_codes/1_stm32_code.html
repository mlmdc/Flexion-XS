STM32 Code Documentation

Architecture(s) du projet

Le projet est basé sur la carte STM32F411, fournie au préalable pour le projet. Le but de la carte est principalement celui d'acquérir des mesures, avec un contrôle de certaines parties pour y arriver. Il est donc naturellement orienté autour d'une boucle périodique d'acquisition des données suivi de l'envoi des données. La partie contrôle se base sur des changements -de valeurs- limités.

La boucle principale

La boucle principale est assurée par le TIM2, à une fréquence de 0.1ms. La période est fixée elle par l'utilisateur, à l'aide de tickTimer_Init(uint32_t ms). A chaque fin de période, une interruption (dont la priorité est la plus haute) est appelée et c'est là que se situe les appels aux fonctions.

ADC

L'acquisition de l'accéléromètre analogique est assuré par l'ADC (Analog to Digital Converter). L'appel à la conversion est normalement bloquant si c'est le processeur qui le fait. Pour pallier au problème, on utilise le DMA, qui appelle à la conversion, puis transfert dans la mémoire le résultat à l'aide d'une interruption.

Le moteur

Le moteur est à la fois un contrôlant et un contrôlé : il y a un encodeur et un PWM.

Le code de l'encodeur est une modification de celui de M. Kerhoas. De même pour le code du hacheur.

Les modifications portées au code de l'encodeur sont les suivantes :

  • On se sépare de l'Index pour compter les tours, puisqu'il n'est pas proposé par l'encodeur.
  • Un compteur global (au fichier speed.c) le remplace.
  • Les fonctions pour l'asservissement ne sont pas prises.

Les modifications portées au code du PWM sont les suivantes :

  • Un degré de précision (0.x) est pris
  • Des fonctions plus poussées que simplement le SetDuty sont proposées.

On rajoute un contrôle de direction sous la forme de 2 signaux logiques directement aux bornes du hacheur. Ils sont mutuellement exclusifs.

//For best accuracy
// The higher the value of alpha, the more closely the EWMA tracks the original time series
float acc_EWMAverage(float* source, float alpha)
{
    //EWMA Formula :
    //EWMA[x] = alpha*source[x] + (1-alpha)*EWMA[x-1]
    //EWMA[0] & init
    float avgd_value = (float)(alpha*source[0])/10.0f;

    for (int i = 1; i < N_CONVERSIONS; i++)
    {
            avgd_value = (float)(alpha*source[i]+(1-alpha)*avgd_value);
    }
    return avgd_value;
}

Description : EWMA pour Exponentially Weighted Moving Average. L'objectif est de donner une moyenne qui prend les derniers résultats avec un plus grand poids par rapport aux premières arrivées. Le nombre de 8 mesures vient de là, il s'agit pour les systèmes binaires d'une valeur n'entraînant pas de sur-calculs. Source.

Paramètres : 1. source : Tableau de float issus de acc_int2flt. 2. alpha : coefficient exponentiel e [0,1]. Plus la valeur est proche de 1, plus le résultat sera proche de la courbe d'origine avec 0 qui donne comme résultat de moyenne 0 et 1 la courbe donnée en paramètre.

Retourne : None

void pidFilter_Compute(void)
{
    /* set k-1 */
    Oe_k[2] = Oe_k[1];
    Oe_k[1] = Oe_k[0];
    Oe_k[0] = command - (float)fabs(output_speed);

    Uc_k[1] = Uc_k[0];

    /* calculate Uc(z) */
    Uc_k[0] = (b2/a2)*Oe_k[0] + (b1/a2)*Oe_k[1] + (b0/a2)*Oe_k[2] - (a1/a2)*Uc_k[1];

    /* no negative voltage */
    if (Uc_k[0] < 0.0f)
    {
        Uc_k[0] = 0.0f;
    }
    else if (Uc_k[0] > 24.0f) /* no voltage superior to 24, both as a command & status*/
    {
        Uc_k[0] = 24.0f;
    }
    /* PWM new duty */
    pwm_SetVoltage(Uc_k[0]);

    debug_tension = Uc_k[0];
}

Description : Fonction principale de ce fichier. Calcule à partir des paramètres du PID (Kp, Kd, Ki) la tension de sortie aux bornes du moteur. La formule de Uc_k[0] est simplement le résultat du développement de la formule initiale du PID, puis de sa conversion dans l'espace discret. fabs() est utilisée puisque seul la vitesse compte dans le calcul, le signe donne par contre la direction (controlée dans mccCommand.c). Destinée uniquement à être appelée dans main.c

Paramètres : None

Retourne : None

uint32_t pulseCalc(float val)
{
    uint32_t pulseVal = 0;

    if (val < 0.0f)
    {
        //If val inf to 0, pulseVal = 0
        pulseVal = (uint32_t)(0x0);
    }
    else if (val > 100.0f)
    {
        //If val sup to 100, pulseVal = 1000
        pulseVal = (uint32_t)(0x3E8);
    }
    else if ((val >= 0.0f) & (val <= 100.0f))
    {
        /* CCR = duty_cycle*ARR <=> CCR = duty_cycle * 100 * ARR(1000)  /100.0f*/
        pulseVal = (uint32_t)(10*val*(1000)/100.0f); // val*10 to keep 0.x precision
        pulseVal = pulseVal/10; // val/10 to be on point
    }
    return pulseVal;
}

Description : Produit à partir d'une valeur de pulsation allant de 0.0 a 100.0 la valeur de CCR1 correspondante. Contient en plus de cela une sécurité sous la forme d'assignements à 0 ou 100 si la valeur en entrée dépasse ces 2 bornes.

Paramètres : val : float correspondant à la valeur de commande. Va de 0.0 à 100.0.

Retourne : La valeur de val multipliée par 10, puis castée en uint32_t.

void pwm_SetVoltage(float voltage)
{
    // Voltage e [0.0,24.0]
    float duty = 0;

    if (voltage < 0.0f)
    {
        //If val inf to 0, duty = 0
        duty = 0.0f;
    }
    else if (voltage > 24.0f)
    {
        //If val sup to 24, duty = 100
        duty = 24.0f;
    }
    else if ((voltage >= 0.0f) & (voltage <= 24.0f))
    {
        duty = (voltage*100.0f)/(24.0f);
    }
    PWM_Value = pulseCalc(duty);
    TIM11->CCR1 = PWM_Value;
}

Description : Définie la valeur du duty cycle, non pas à partir d'un pourcentage mais d'une tension. Une seconde sécurité est mise en place sous la forme d'un anti-dépassement de la tension max du moteur.

Paramètres : voltage : Valeur de tension dont sera issue le duty cycle. En float pour permettre de la précision qui peut être cependant supprimée par le passage en int.

void slice_str(const char * str, char * buffer, size_t start, size_t end)
{
    size_t j = 0;
    for ( size_t i = start; i <= end; ++i ) {
        buffer[j++] = str[i];
    }
    buffer[j] = 0;
}

Description : Découpe un string dont le début du découpage est start et la fin du découpage est stop. Le résultat n'est pas renvoyé, ni même la quantité de caractères traités. Dépose le résultat dans buffer.

Paramètres : - str : String (pointeur de char) issu d'une variable OU directement mis en entrée avec "...". - buffer : String où le résultat est remis. - start : N'importe quel entier d'où le découpage démarre. - stop : N'importe quel entier où se finit le découpage. A noter que si end est supérieur ou égal au nombre de caractères de str, alors end ne fait pas effet.

Retourne : None

char * slice_str_r(const char * str, size_t start, size_t end)
{
    char * buffer;
    size_t j = 0;
    for (size_t i = start; i <= end; ++i ) {
          buffer[j++] = str[i];
    }
    buffer[j] = 0;
    return buffer;
}

Description : Découpe un string dont le début du découpage est start et la fin du découpage est stop. Le résultat est renvoyé, sous forme d'un tableau de caractères complet.

void comm_SliceInput(const char * input, char * identifier, char *value)
{
    char tmp_value[RX_BUFFER_SIZE-4];
    char *tmp_slice;
    char *tmp_out_value;
    /* Slice input string from 0 to 3 == the identifier of shape 0xXX */
    slice_str(input, identifier, 0, 3);

    /* Slice input string from 5 to buffer size -1 == the value*/
    slice_str(input, tmp_value, 4, RX_BUFFER_SIZE-1); // rest of the string

    /* cast from char*[RX_BUFFER_SIZE-4], incompatible with strsep, to char * */
    tmp_slice = (char *)tmp_value;
    /* SEParate the string with ; as delimiter, keeps the string before ; */
    tmp_out_value = strsep(&tmp_slice, ";");
    strcpy(value,tmp_out_value);
}

Paramètres : - input : String reçu, sans taille. - identifier : Variable externe à la fonction sensée recevoir l'identifiant du message. - value : Variable externe sensée recevoir la valeur du message.
